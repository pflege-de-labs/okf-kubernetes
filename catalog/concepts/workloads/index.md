# Workloads

* [Pods](pods.md) - _Pods_ are the smallest deployable units of computing that you can create and manage in Kubernetes. ([contents](pods/index.md))
* [Workload Management](controllers.md) - Kubernetes provides several built-in APIs for declarative management of your workloads and the components of those workloads. ([contents](controllers/index.md))
* [Managing Workloads](management.md) - You've deployed your application and exposed it via a Service.
* [Autoscaling Workloads](autoscaling.md) - With autoscaling, you can automatically update your workloads in one way or another. This allows your cluster to react to changes in resource demand more elastically and efficiently. ([contents](autoscaling/index.md))
* [Workload API](workload-api.md) - The `Workload` API resource defines the scheduling requirements and structure of a multi-Pod application. ([contents](workload-api/index.md))
* [PodGroup API](podgroup-api.md) - A PodGroup is a runtime object that represents a group of Pods scheduled together as a single unit. ([contents](podgroup-api/index.md))
* [CompositePodGroup API](compositepodgroup-api.md) - A `CompositePodGroup` is a runtime object that represents a non-leaf node in a multi-level workload hierarchy. ([contents](compositepodgroup-api/index.md))
