# Policies

* [Limit Ranges](limit-range.md) - By default, containers run with unbounded compute resources on a Kubernetes cluster.
* [Resource Quotas](resource-quotas.md) - When several users or teams share a cluster with a fixed number of nodes, there is a concern that one team could use more than its fair share of resources.
* [Process ID Limits And Reservations](pid-limiting.md) - Kubernetes allow you to limit the number of process IDs (PIDs) that a Pod can use.
