# Containers

* [Images](images.md) - A container image represents binary data that encapsulates an application and all its software dependencies.
* [Container Environment](container-environment.md) - This page describes the resources available to Containers in the Container environment.
* [Runtime Class](runtime-class.md) - This page describes the RuntimeClass resource and runtime selection mechanism.
* [Container Lifecycle Hooks](container-lifecycle-hooks.md) - This page describes how kubelet managed Containers can use the Container lifecycle hook framework to run code triggered by events during their management lifecycle.
* [Container Runtime Interface (CRI)](cri.md) - The CRI is a plugin interface which enables the kubelet to use a wide variety of container runtimes, without having a need to recompile the cluster components.
