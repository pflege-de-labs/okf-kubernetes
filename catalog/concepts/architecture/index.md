# Cluster Architecture

* [Nodes](nodes.md) - Kubernetes runs your workload by placing containers into Pods to run on _Nodes_.
* [Communication between Nodes and the Control Plane](control-plane-node-communication.md) - This document catalogs the communication paths between the API server and the Kubernetes cluster.

* [Leases](leases.md) - Distributed systems often have a need for _leases_, which provide a mechanism to lock shared resources and coordinate activity between members of a set.
* [Cloud Controller Manager](cloud-controller.md) - Cloud infrastructure technologies let you run Kubernetes on public, private, and hybrid clouds.
* [About cgroup v2](cgroups.md) - On Linux, control groups constrain resources that are allocated to processes.
* [Kubernetes Self-Healing](self-healing.md) - Kubernetes is designed with self-healing capabilities that help maintain the health and availability of workloads.
* [Garbage Collection](garbage-collection.md) - Garbage collection is a collective term for the various mechanisms Kubernetes uses to clean up cluster resources.
* [Mixed Version Proxy](mixed-version-proxy.md) - Kubernetes 1.37 includes a beta feature that lets an API Server proxy resource requests to other _peer_ API servers.
