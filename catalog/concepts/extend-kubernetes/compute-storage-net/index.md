# Compute, Storage, and Networking Extensions

* [Network Plugins](network-plugins.md) - Kubernetes (version 1.3 through to the latest 1.37, and likely onwards) lets you use Container Network Interface (CNI) plugins for cluster networking.
* [Device Plugins](device-plugins.md) - Device plugins let you configure your cluster with support for devices or resources that require vendor-specific setup, such as GPUs, NICs, FPGAs, or non-volatile main memory.
