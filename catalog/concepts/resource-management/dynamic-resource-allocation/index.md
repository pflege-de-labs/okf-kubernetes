# Dynamic Resource Allocation

* [DRA API Objects](dra-api.md) - This page describes the Kubernetes API kinds that dynamic resource allocation (DRA) uses to categorize, request, and allocate devices.
* [How DRA Works](how-dra-works.md) - This page describes how Kubernetes allocates devices to workloads with dynamic resource allocation (DRA), and how pre-scheduled Pods interact with the process.
* [Observability of Dynamic Resources](dra-observability.md) - This page describes how to observe the status and health of resources that are dynamically allocated with DRA.
* [DRA Features](dra-features.md) - This page describes optional DRA features for advanced use cases.
* [Device Taints and Tolerations](device-taints.md) - This page describes device taints and tolerations in DRA, which let drivers and admins keep Pods off specific devices, or evict Pods already using them.
