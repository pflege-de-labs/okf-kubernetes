# Administration with kubeadm

* [Adding Linux worker nodes](adding-linux-nodes.md) - This page explains how to add Linux worker nodes to a kubeadm cluster.
* [Adding Windows worker nodes](adding-windows-nodes.md) - This page explains how to add Windows worker nodes to a kubeadm cluster.
* [Upgrading kubeadm clusters](kubeadm-upgrade.md) - This page explains how to upgrade a Kubernetes cluster created with kubeadm from version 1.36.x to version 1.37.x, and from version 1.37.x to 1.37.y (where `y > x`).
* [Upgrading Linux nodes](upgrading-linux-nodes.md) - This page explains how to upgrade a Linux Worker Nodes created with kubeadm.
* [Upgrading Windows nodes](upgrading-windows-nodes.md) - This page explains how to upgrade a Windows node created with kubeadm.
* [Certificate Management with kubeadm](kubeadm-certs.md) - Client certificates generated by kubeadm expire after 1 year.
* [Reconfiguring a kubeadm cluster](kubeadm-reconfigure.md) - kubeadm does not support automated ways of reconfiguring components that were deployed on managed nodes.
* [Changing The Kubernetes Package Repository](change-package-repository.md) - This page explains how to enable a package repository for the desired Kubernetes minor release upon upgrading a cluster.
