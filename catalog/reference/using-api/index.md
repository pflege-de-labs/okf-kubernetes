# API Overview

* [Declarative API Validation](declarative-validation.md) - Kubernetes 1.37 uses _declarative validation_ for a growing set of APIs.
* [Kubernetes API Concepts](api-concepts.md) - The Kubernetes API is a resource-based (RESTful) programmatic interface provided via HTTP.
* [Server-Side Apply](server-side-apply.md) - Kubernetes supports multiple appliers collaborating to manage the fields of a single object.
* [Client Libraries](client-libraries.md) - This page contains an overview of the client libraries for using the Kubernetes API from various programming languages.
* [Common Expression Language in Kubernetes](cel.md) - The Common Expression Language (CEL) is used in the Kubernetes API to declare validation rules, policy rules, and other constraints or conditions.
* [Deprecated API Migration Guide](deprecation-guide.md) - As the Kubernetes API evolves, APIs are periodically reorganized or upgraded.
* [Kubernetes API health endpoints](health-checks.md) - The Kubernetes API server provides API endpoints to indicate the current status of the API server.
