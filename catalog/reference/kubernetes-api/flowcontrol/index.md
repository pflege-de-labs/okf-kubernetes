# Flowcontrol

* [FlowSchema](flow-schema-v1.md) - FlowSchema defines the schema of a group of flows. Note that a flow is made up of a set of inbound API requests with similar attributes and is identified by a pair of strings: the name of the FlowSchema and a &#34;flow distinguisher&#34;.
* [PriorityLevelConfiguration](priority-level-configuration-v1.md) - PriorityLevelConfiguration represents the configuration of a priority level.
