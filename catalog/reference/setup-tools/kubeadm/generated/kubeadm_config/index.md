# kubeadm_config

* [kubeadm_config_images](kubeadm_config_images.md) - Interact with container images used by kubeadm
* [kubeadm_config_images_list](kubeadm_config_images_list.md) - Print a list of images kubeadm will use.
* [kubeadm_config_images_pull](kubeadm_config_images_pull.md) - Pull images used by kubeadm
* [kubeadm_config_migrate](kubeadm_config_migrate.md) - Read an older version of the kubeadm configuration API types from a file, and output the similar config object for the newer version
* [kubeadm_config_print](kubeadm_config_print.md) - Print configuration
* [kubeadm_config_print_init-defaults](kubeadm_config_print_init-defaults.md) - Print default init configuration, that can be used for 'kubeadm init'
* [kubeadm_config_print_join-defaults](kubeadm_config_print_join-defaults.md) - Print default join configuration, that can be used for 'kubeadm join'
* [kubeadm_config_print_reset-defaults](kubeadm_config_print_reset-defaults.md) - Print default reset configuration, that can be used for 'kubeadm reset'
* [kubeadm_config_print_upgrade-defaults](kubeadm_config_print_upgrade-defaults.md) - Print default upgrade configuration, that can be used for 'kubeadm upgrade'
* [kubeadm_config_validate](kubeadm_config_validate.md) - Read a file containing the kubeadm configuration API and report any validation problems
