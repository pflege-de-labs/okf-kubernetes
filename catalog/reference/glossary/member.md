# Member

A continuously active [contributor](/reference/glossary/contributor.md) in the K8s community.

 

Members can have issues and PRs assigned to them and participate in [special interest groups (SIGs)](/reference/glossary/sig.md) through GitHub teams. Pre-submit tests are automatically run for members' PRs. A member is expected to remain an active contributor to the community.
