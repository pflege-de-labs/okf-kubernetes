# ResourceClaim

Describes the resources that a workload needs, such as
[devices](/reference/glossary/device.md). ResourceClaims are
used in
[dynamic resource allocation (DRA)](/concepts/resource-management/dynamic-resource-allocation.md)
to provide Pods with access to a specific resource.

ResourceClaims can be created by workload operators or generated by Kubernetes
based on a
[ResourceClaimTemplate](/reference/glossary/resourceclaimtemplate.md).
