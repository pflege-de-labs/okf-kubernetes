# Service Catalog

A former extension API that enabled applications running in Kubernetes clusters to easily use external managed software offerings, such as a datastore service offered by a cloud provider.

 

It provided a way to list, provision, and bind with external [Managed Services](/reference/glossary/managed-service.md) without needing detailed knowledge about how those services would be created or managed.
