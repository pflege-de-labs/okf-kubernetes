# Component tools

* [Feature Gates](feature-gates.md) - This page contains an overview of the various feature gates an administrator can specify on different Kubernetes components.
* [Feature Gates (removed)](feature-gates-removed.md) - This page contains list of feature gates that have been removed.
* [kube-apiserver](kube-apiserver.md) - The Kubernetes API server validates and configures data for the api objects which include pods, services, replicationcontrollers, and others.
* [kube-controller-manager](kube-controller-manager.md) - The Kubernetes controller manager is a daemon that embeds the core control loops shipped with Kubernetes.
* [kube-proxy](kube-proxy.md) - The Kubernetes network proxy runs on each node.
* [kube-scheduler](kube-scheduler.md) - The Kubernetes scheduler is a control plane process which assigns Pods to Nodes.
* [kubelet](kubelet.md) - The kubelet is the primary "node agent" that runs on each node.
